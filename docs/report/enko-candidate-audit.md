# 한·영 후보 누락 진단 — 2026-10-19

**주요 병목은 후보 개수보다 언어·경로 선택이다.** 짧은 영어 단어를 한국어 문장에
넣은 세트의 토큰 오류 312건 중 311건은 정답을 단일 언어로 출력할 수 있는 선택 오류였다.
탐색 생략 조건을 전부 해제하는 실험은 일반 한국어 품질이 하락하여 기각했다.
제품 판별 동작은 변경하지 않았다.

## 방법과 범위

기준 `5816b5d`, Windows x64 release lab 0.2.4. 이전과 같은 자료 및
`--profile enko --fold 0/3 --corpus 3000 --misses 12` 조건을 사용했다.
자료 해시는 [앞선 실험 기록](enko-experiments.md)에 있다.

`--audit-enko`는 실제 `TextConverter`를 두 번 실행한다. 첫 결과는 기존 오른쪽 문맥
보정을 포함한 문장 정확도, 두 번째 결과는 보정 없는 왼쪽→오른쪽 문장 정확도다.
두 번째 경로에서 실제 전달된 문맥을 기록하고 **오답 토큰**의 원인을 분류한다.
정답의 언어를 이전 문맥에 넣거나 미래 단어를 진단 문맥에 제공하지 않는다.

혼합 후보 검사는 기존 격자 생성과 `search`의 전이 제약을 재사용한다. 정답의 각 문자와
그 문자를 입력한 키 범위를 대응시키고, 정답 출력과 일치하는 간선만 남겨 다시 검색한다.
이렇게 해야 원래 1등 경로에 밀린 정답도 검사할 수 있다. 같은 간선 위에서 전이 제약을
무시한 도달 여부도 따로 계산하여 간선 누락과 전이 차단을 구분한다. 진단은 별도 캐시와
표를 사용하고 일반 lab 지연 측정에는 실행되지 않는다.

오류 분류 순서는 아래와 같다. 단일 언어 출력 오류와 혼합 경로 오류를 구분한다.

| 분류 | 의미 |
| --- | --- |
| `pure-selection` | 원래 키 또는 전체 한글 조합이 정답인데 다른 출력을 선택. 점수·정책 오류를 함께 포함 |
| `missing-edge` | 정답과 일치하는 간선만으로 끝까지 도달할 수 없음 |
| `blocked-transition` | 간선은 연결되지만 기존 전이 제약으로 정답 경로를 구성할 수 없음 |
| `skip-gate` | 정답 경로가 있고 탐색 생략만 없애면 기존 점수로 정답이 선택됨 |
| `skip-and-selection` | 정답 경로가 있으나 탐색 생략과 경로 선택을 둘 다 바꿔야 함 |
| `lattice-selection` | 탐색을 실행하고 정답 경로도 있지만 기존 경로 선택에서 정답을 선택하지 않음 |
| `outside-lattice` | 격자의 선택 결과는 정답인데 전체 엔진 출력이 다름 |
| `unaligned`, `unsupported` | 문자·키 대응 또는 진단 범위 밖 입력. 평가에서 조용히 제외하지 않음 |

후보가 존재한다는 사실은 점수를 학습하면 반드시 해결된다는 뜻이 아니다. 입력 자체의
모호성, 학습 자료의 정보량, 상위 정책도 영향을 준다. 점수나 단어 예외는 조정하지 않았다.

## 원인별 측정

| 세트 | 토큰 수 | 토큰 오류 | 단일 언어 선택 | 간선 누락 | 전이 차단 | 생략만 해결 | 생략+선택 | 격자 선택 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| 실제 한국어 문장 | 16,491 | 48 | 38 | 5 | 0 | 0 | 1 | 4 |
| 실제 영어 문장 | 21,692 | 2 | 2 | 0 | 0 | 0 | 0 | 0 |
| 짧은 영어 단독 삽입 | 6,190 | 312 | 311 | 1 | 0 | 0 | 0 | 0 |
| 짧은 영어+조사 삽입 | 6,074 | 422 | 12 | 2 | 0 | 48 | 292 | 68 |

모든 세트에서 `outside-lattice`, `unaligned`, `unsupported`는 0건이었다.
합성 세트는 같은 한국어 문장을 재사용하므로 표의 오류를 독립 표본처럼 합산하지 않는다.
합성 세트의 토큰 오류에는 삽입한 단어뿐 아니라 원래 문장의 토큰도 포함된다.

짧은 영어 단독 삽입의 문장 정답 수는 오른쪽 문맥 보정 포함 559/864(64.70%), 보정 없이
555/864(64.24%)였다. 토큰 오류의 약 99.7%가 단일 언어 선택이다. 예를 들면 `dna`→`움`,
`to`→`새`, `so`→`내`로 바뀐다. 이 세트의 65%를 혼합어 경계 후보 누락률로 해석하면 안 된다.

짧은 영어+조사는 문장 정답 435/844(51.54%), 보정 없이 430/844(50.95%)였다. 일반 lab의
기존 짧은 영어 단독 삽입 지표와는 다른 세트다. 탐색이 생략된 오답 340건 중 48건은
생략만 없애면 정답이 선택되지만, 나머지 292건은 선택도 바뀌어야 한다.

실제 간선 누락 사례로 `앤e`, `시x`, `마초b급` 등이 있다. 전체 누락률은 작다.
이 소수 사례 때문에 전역 후보 제약을 완화하는 작업의 우선순위를 높이지 않았다.

## 탐색 생략 해제 실험

`LAB_ENKO_FULL_SEARCH=1`은 기존 탐색 생략 조건만 해제한다. 간선·전이·가중치·margin은
유지한다. 이 스위치는 `tuning` 빌드에만 존재하고 lab에서 enko와 기존 엔진만 허용한다.
일반 lab 전체 평가와 별도 후보 진단을 모두 실행했다.

| 문장 정확도 (%) | 기본값 | 생략 해제 |
| --- | ---: | ---: |
| 한국어 문장 | 99.13 | 98.63 |
| 영어 문장 | 99.93 | 99.93 |
| 기존 용어+조사 | 99.06 | 98.60 |
| 짧은 영어 단독 삽입 | 64.70 | 63.89 |
| 짧은 영어+조사 삽입 (진단 세트) | 51.54 | 57.11 |

공통 `acc.ALL`도 99.69→99.64%로 하락했다. 짧은 영어+조사에서 +5.57%p였지만,
일반 한국어와 다른 혼합 세트의 회귀 때문에 **기각**했다. 실행별 부하를 통제한 반복
지연 비교는 하지 않았으므로 이 실험의 속도 변화율은 보고하지 않는다.

다음 학습의 우선순위는 실제 혼합 문맥에서 단일 언어와 혼합 경로를 함께 선택하는 점수다.
키별 언어 태그 학습이나 구간 후보 확대만으로는 단독 영어 선택의 주된 병목을 해결하지
못할 수 있다. 출처·문서별로 분리한 실제 혼합 자료가 필요하며, 무작위로 영어를 삽입한
합성 자료만으로 일반 사용자 품질 개선을 주장하지 않는다.

## 재현과 회귀 확인

명령은 [lab README](../../lab/README.md)의 후보 누락 진단 항목에 있다.
원시 로그, 실행 계획, 변경 전 실행 파일은 로컬 `temp/enko-candidates/`에 보관한다.
기본값의 정확도·시나리오·미리보기 관련 지표 121개가 변경 전 실행 파일과 동일하다.
정답 스냅샷이나 저장된 baseline은 갱신하지 않았다.

진단 테스트는 정답 경로의 도달, 낮은 순위 정답 보존, 간선과 전이 차단의 구분,
Unicode 문자 경계, 일반 탐색 캐시 보존을 검사한다. OS 화면 지연이나 네이티브 IME
이벤트 재생은 이번 검사의 범위 밖이다.
