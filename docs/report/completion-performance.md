# 사용자 자동완성 탐색 최적화

측정일: 2026-10-19. 기준 코어: `0b1e206` (0.10.4).
현재 작업 트리와 같은 lab의 세션 측정 코드를 기준 코어에도 붙여 비교했다.
최종 lab 버전은 0.2.5이며 기존 평가 세트와 지표의 정의는 바꾸지 않았다.

## 반영한 변경

`History::suggest()`가 마지막 글자를 뺀 접두어 전체를 순회하던 경로를 줄였다.
이전에는 한 글자를 입력하면 최대 2만 단어 전체를 검사했다.
이제 정확히 일치하는 접두어와 미완성 한글이 될 수 있는 음절 구간만
기존 BTreeMap에서 읽는다. 한글 구간은 기존 초성 인덱스와 Unicode 음절 구조로 계산한다.
결과의 빈도·길이·동률 순서, 추천 최소 횟수와 사용자 기록 형식은 그대로다.
빈 기록은 즉시 반환한다. 새 의존성이나 캐시는 추가하지 않았다.

언어 판별 점수·임계값·가중치·사전·단어 예외·학습 방식은 변경하지 않았다.
합성 기록은 측정용이며 판별기 학습이나 가중치 조정에 쓰지 않았다.

## 세션 지연

Windows release 빌드, 이전·중간·최종 실행 파일을 순서를 번갈아 5회씩 실행한
각 지표의 중앙값이다. 빌드와 테스트는 측정과 동시에 실행하지 않았다.
단위는 µs다. 기록은 영어와 한글을 섞은 합성 데이터다.

| 프로필 | 기록 수 | 지표 | 이전 | 최종 | 변화 |
| --- | ---: | --- | ---: | ---: | ---: |
| 영·한 | 0 | 세션 평균 | 24.758 | 26.760 | +8.1% |
| 영·한 | 1,000 | 세션 평균 | 27.179 | 24.285 | -10.6% |
| 영·한 | 20,000 | 세션 평균 | 108.896 | 25.506 | -76.6% |
| 영·한 | 20,000 | 세션 p99 | 902.600 | 88.000 | -90.3% |
| 영·한·일 | 0 | 세션 평균 | 81.880 | 71.652 | -12.5% |
| 영·한·일 | 1,000 | 세션 평균 | 70.085 | 70.811 | +1.0% |
| 영·한·일 | 20,000 | 세션 평균 | 92.970 | 66.259 | -28.7% |
| 영·한·일 | 20,000 | 세션 p99 | 413.600 | 179.100 | -56.7% |

작은 기록에서의 ±13% 수준 차이는 실행 편차와 겹쳐 개선·회귀로 판단하지 않는다.
기록 2만 개에서 영·한의 직접 탐색 평균은 `p` 873.838→8.797,
`ㄱ` 352.088→9.139, `가` 342.761→1.496µs였다.
분포가 한 접두어에 몰리면 여전히 일치 후보 수만큼 순회하므로 이 배율을 일반화하지 않는다.

세션 지표는 `InputSession.handle()`과 `suggestion()`의 합이다.
워밍업 후 키 입력을 측정하며 NoopClient를 사용한다.
단어 확정·디스크 저장·TSF/화면 반영·일본어 실시간 한자 변환은 포함하지 않는다.
기존 `keystroke.*` 판별 지표와 구분해야 한다.

## 정확도와 회귀 확인

기존 단어·문장·시나리오 평가와 코퍼스 `--corpus 3000 --fold 2/3`를
두 프로필에서 이전·최종 빌드로 실행했다. `--misses 10000`으로 상세 출력도 비교했다.

- 영·한: 품질 지표 121개와 오답 진단 출력 544줄 일치. `acc.ALL` 99.69% 유지.
- 영·한·일: 품질 지표 149개와 오답 진단 출력 594줄 일치. `acc.ALL` 99.52% 유지.
- 위 품질 지표는 시간·메모리 지표를 제외한 정확도·미리보기 안정성 등의 출력이다.
- 전체 코어 테스트 294개 통과 후, 최종 자동완성 변경은 관련 테스트 11개를 다시 통과했다.
- 새 동등성 테스트는 한글 11,172개 음절을 포함한 기록에서 초성 19개,
  받침 없는 음절 399개 및 영어·빈 입력·복합 접두어를 기존 전체 탐색과 비교한다.
- lab 테스트 9개, Windows TIP·설정 앱의 일본어 기능 포함 `cargo check`, 포맷 검사 통과.

최종 판별 단독 지연도 확인했다. 영·한 `keystroke.avg_us`는 8.88→8.83,
영·한·일은 27.98→27.87µs로, 이 단일 비교에서는 사실상 같다.
이번 개선은 판별 알고리즘이 아니라 사용자 자동완성 경로에 해당한다.

## 제외한 실험

설명 문자열·문자 배열 할당 축소는 교대 측정에서 일관된 속도 개선이 없어 되돌렸다.
키보드 훅의 250ms 설정 조회 제한은 설정 반영 시간을 바꾸므로 제외했다.
문맥이 다른 판별 결과를 공유하는 캐시나 저장 시점 변경도 이번 변경에 넣지 않았다.

## 재현

```powershell
cargo build --release --manifest-path lab/Cargo.toml
lab/target/release/tacit-lab.exe --profile enko --session
lab/target/release/tacit-lab.exe --profile enkoja --session
lab/target/release/tacit-lab.exe --profile enko --corpus 3000 --fold 2/3 --misses 10000 --steady
lab/target/release/tacit-lab.exe --profile enkoja --corpus 3000 --fold 2/3 --misses 10000 --steady
```

전후 비교는 같은 lab·데이터·빌드 설정을 쓰고 실행 파일을 번갈아 실행한다.
측정 원본과 중간 실험 출력은 로컬 `temp/performance/`에 보관했다.
